VPN – Virtual Private Network

VPN allows secure access to the Internet or company networks. It encrypts your data, protecting it from spies. Example: Remote work access to company servers.

VLAN – Virtual LAN

VLAN divides a single network into multiple logical networks. Example: Employees, management, and guests have separate networks even on the same switch.

ACL – Access Control List

ACL defines rules on routers or switches: who can access and who is blocked. Example: Allow a specific network to reach the server, block others.

Routing

Routing determines the path data takes from one network to another. Routers select the best path using the Routing Table. Types: Static or Dynamic (OSPF, EIGRP).

SD-WAN – Software-Defined WAN

SD-WAN manages wide area networks using software for flexibility, security, and cost efficiency. Example: Connecting multiple branches of a company efficiently.

Subnetting

Subnetting divides a network into smaller sub-networks. Example: 192.168.1.0/24 can be split into 192.168.1.0/26, 192.168.1.64/26… Helps with organization, security, and efficient IP usage.

Firewalls

Firewalls control incoming and outgoing network traffic based on security rules. Example: Block unauthorized access while allowing trusted traffic.

NAT – Network Address Translation

NAT translates private IP addresses to public IP addresses for Internet access. Example: Multiple devices in a home share one public IP.

Encryption

Encryption secures data by converting it into unreadable format. Example: HTTPS websites use SSL/TLS encryption to protect traffic.

Antivirus / Anti-malware

Software that protects computers from viruses, malware, and ransomware. Example: Windows Defender, Avast, or Bitdefender.

IDS / IPS – Intrusion Detection / Prevention System

IDS monitors network traffic for suspicious activity; IPS blocks threats automatically. Example: Detect and prevent unauthorized access attempts.

Phishing

Phishing is a cyber attack to steal sensitive info via fake emails or websites. Protect yourself by checking links and verifying senders.

Secure Passwords

Strong passwords prevent unauthorized access. Example: Use a mix of letters, numbers, symbols, and avoid dictionary words.

Backups

Regular backups protect against data loss. Example: Cloud backups or external drives.

Two-Factor Authentication (2FA)

Adds a second layer of security by requiring a code in addition to a password. Example: SMS codes, Authenticator apps.

OSI Model – 7 Layers

  1. Physical (Layer 1): Cables, switches, network devices.
  2. Data Link (Layer 2): MAC addresses, frame delivery, switches.
  3. Network (Layer 3): IP addresses, routing, routers.
  4. Transport (Layer 4): TCP/UDP, reliable data transfer.
  5. Session (Layer 5): Establish/terminate sessions between applications.
  6. Presentation (Layer 6): Data formatting, encryption, compression.
  7. Application (Layer 7): Network services for applications: HTTP, FTP, Email.
